# LangChain Fundamentals

A numbered sequence of small, single-file lessons building up LangChain concepts one at a time,
from a single chat call to a full RAG chatbot. See `0-0workflow.md` for the conceptual pipeline
these lessons walk through (document loading → splitting → embeddings → vector store → retriever).

| File | Concept |
|---|---|
| `0-langchain101.py` | First call to an LLM through LangChain's chat model interface. |
| `1-using_text_loaders.py` | Loading a `.txt` file with `TextLoader`, embedding it, storing in FAISS. |
| `2-using_pdf_loader.py` | Loading a PDF with `PyPDFLoader`. |
| `3-using_dir_loader.py` | Loading every file in a directory at once with `DirectoryLoader`. |
| `4-using_chains.py` | Composing a prompt → model → output-parser chain with LCEL (`|` pipe syntax). |
| `5-using_langchain_RAG.py` | Putting it together: load → split → embed → retrieve → answer, the smallest end-to-end RAG example in this repo. |
| `6-chatbot.py` | A persistent-memory chatbot using Ollama + a Chroma-backed vector store and a Selenium URL loader for web content. |

For the two bigger, app-level RAG implementations that build on these ideas, see
[`../rag-complex/`](../rag-complex/readme.md) and [`../rag-pdf/`](../rag-pdf/readme.md).

## Prerequisites

- An `OPENAI_API_KEY` in a local `.env` file (gitignored) for the lessons that use OpenAI.
- [Ollama](https://ollama.com) running locally for `6-chatbot.py`.
- `files/MLA-C01.pdf` at the repo root (used by lessons 2 and 3).

## Install & run

```bash
pip install -r requirements.txt
python 0-langchain101.py   # or any other lesson file
```

## Notes

- `db/` (this folder's local Chroma persistence directory) is gitignored — it's generated by
  `6-chatbot.py`, not source.
- ⚠️ Lessons `1-using_text_loaders.py` and `5-using_langchain_RAG.py` reference
  `files/twin_ai_agent.txt`, which isn't present in this repo (`files/` is gitignored, and this
  particular fixture was never checked in). Add your own `.txt` file at that path, or point the
  loader at `files/MLA-C01.pdf` instead, before running those two.
