# Project Planner

# ================Agent================
- **Agent**: 
A digital assistant that can perform tasks, make decisions, and interact with users. 
Agents can be simple or complex, depending on their capabilities and the tasks they are designed to perform.
In this case, we need 3 agents:
- Project Planner
- Estimation Analyst
- Allocation Strategist

- **Task**:
- Task Breakdown
- Time Estimation
- Resource Allocation


- **Goals**:
- Create a detailed project plan: task, allocations, milestones
